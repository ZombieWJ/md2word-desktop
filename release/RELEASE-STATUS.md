# 发布状态

当前应用版本0.1.0-rc.6，为预发布版本；是否已开放下载以GitHub实际Release为准。自有源码及CN-General模板采用MIT；源码展示与包含第三方程序的软件发行分别验收。

本轮仅提供当前用户安装的离线Setup.exe，便携ZIP仅本地保留，不上传。两者包含相同应用、运行时、Pandoc和模板，不要求用户安装SDK或Word才能转换。候选包未签名，安装记录中的ZombieWJ发布者名称不等同于数字签名认证。

## 软件发行前待完成

可下载预发布包要求干净源码、模板许可证据、Pandoc完整源码构建材料及核心、桌面和包内转换检查通过。工作流仅上传草稿，本机复核后按维护者授权公开；不把未完成的兼容性验证记为已通过。正式v0.1.0仍保留完整验收要求。

- Pandoc二进制对应的完整源码、精确依赖及构建材料。现有3.10标签源码归档不能直接视为材料齐全。
- 预发布打包只接受通过verify-pandoc-bundle.ps1核对的自行构建程序及完整源码包；其记录见包内pandoc/SOURCE.json和Release源码材料。开发环境中的官方二进制仍单独保留来源及未核清项目。
- 无开发环境Windows10/11目标电脑的实际断网安装、转换、升级、卸载和重装。
- 原生对话框、拖放、键盘、实际缩放及跨屏等尚未取得记录的检查。

Windows10本机运行结果与微软对具体版本的官方支持范围分别记录；当前专业版22H2的实测不表示其属于.NET10官方支持列表。WPS及其他Word版本未通过验收。

正式Release计划提供Setup.exe、自有源码、Pandoc完整对应源码与构建材料、校验值及第三方说明。源码材料可采用ZIP归档，与不上传的便携程序ZIP用途不同。release/public-readiness.json控制发行门槛，正式构建要求检查证据、干净源码、对应Git标签及非候选版本号；不能仅修改状态绕过检查。
