# 发布状态

当前应用版本0.1.0-rc.5，安装包公开下载仍待发行材料核对。自有源码及CN-General模板采用MIT；源码展示与包含第三方程序的软件发行分别验收。

主要交付方式为当前用户安装的离线Setup.exe，备用为完整便携ZIP；两者包含相同应用、运行时、Pandoc和模板，不要求用户安装SDK或Word才能转换。候选包未签名，安装记录中的ZombieWJ发布者名称不等同于数字签名认证。

## 已有验证

44项核心及23项桌面自动检查、53项便携检查、38项试用材料检查通过；本机覆盖升级保留设置、安装目录和快捷方式。Microsoft Word15.0/Build15.0.5589下13份固定样例共16页已逐页复查。范围及限制见[当前状态](../docs/开发计划与验收.md)。

维护者已确认实机安装、转换及卸载通过，环境详情待补充，见[实机记录](../docs/实机验证记录.md)。3名非开发用户试用按维护者要求移至后续，不作为本轮强制前置条件，未记为通过。

## 软件发行前待完成

- Pandoc二进制对应的完整源码、精确依赖及构建材料。现有3.10标签源码归档不能直接视为材料齐全。
- 无开发环境Windows10/11目标电脑的实际断网安装、转换、升级、卸载和重装。
- 原生对话框、拖放、键盘、实际缩放及跨屏等尚未取得记录的检查。

Windows10本机运行结果与微软对具体版本的官方支持范围分别记录；当前专业版22H2的实测不表示其属于.NET10官方支持列表。WPS及其他Word版本未通过验收。

正式Release计划同时提供Setup.exe、备用ZIP、自有源码、Pandoc完整对应源码与构建材料、校验值及第三方说明。release/public-readiness.json控制发行门槛，正式构建要求检查证据、干净源码、对应Git标签及非候选版本号；不能仅修改状态绕过检查。
