# 表格排版示例

这是一份合成演示文档，用于查看中文表头、边框、单元格留白和正文宽度。

## 转换检查表

| 检查项目 | 查看内容 | 示例数据 |
|---|---|---|
| 表头 | 表头文字加粗、居中，使用白色背景。 | 中文表头 |
| 单元格 | 上下留白，文字清楚，边框完整。 | 第一行 |
| 长内容 | 这一格使用较长的说明文字，检查内容自然换行后仍然处于表格边界之内。 | 多行内容 |
| 数字 | 不改变原始精度和数值。 | 123.45 |
| 单位 | 保留数值、单位和大小写。 | 0.60 L/min |
| 技术标识 | 保留原始技术文本。 | CAN ID、0x0A |

## 表格后的正文

表格之后可以继续编辑普通正文。此示例仅展示这一份固定输入的结果，不代表任意宽表都能自动得到相同效果。
