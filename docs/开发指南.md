# 开发指南

面向中文文档的离线转换工具，输出可编辑的DOCX。主要交付包含Pandoc的Windows10/11 x64离线安装包，便携ZIP作为备用。

## 当前状态

转换核心、命令行和WinForms桌面界面已接入真实转换。支持图片、长文、宽表、跨页表格、批量队列、重名另存、取消与失败重试；桌面界面支持多文件选择与拖入、移除和清空、模板与输出设置、结果打开及设置保存。

已有包含运行时、Pandoc和模板的自包含候选包构建入口。模板采用MIT；Pandoc完整对应源码及干净目标环境检查尚未完成，正式下载暂未开放。验证范围见[当前状态](开发计划与验收.md)。

## 使用桌面程序

安装后的应用从开始菜单打开；便携版运行解压目录中的Md2Word.Desktop.exe。源码开发使用PowerShell7.2或更高版本，在项目根目录构建后运行：

```powershell
pwsh -File .\scripts\start.ps1
```

开发启动入口使用.tools/dotnet中的项目运行时和已校验的Pandoc。启动失败时在终端保留错误提示；启动检查同时验证正常显示和隐藏窗口两种情况，避免只检查进程存在或退出码。

1. 添加或拖入Markdown文件，可一次选择多个文件。重复文件自动略过；同名但不同目录的文件可同时添加，悬停文件名查看完整路径。
2. 每次打开默认选择“中文通用”，也可切换为“保留原有列表和加粗”。可保存到源文件目录，或选择指定文件夹；默认提取开头的一级标题。
3. 点击“转换N个文件”。运行期间锁定模板、输出位置和文件增删，显示真实文件序号和当前阶段。
4. 成功后点击“打开文档”或“在文件夹中显示”；警告或失败时展开“查看原因”。主按钮只处理待转换及已取消文件；失败项单独重试；已完成文件右键“重新转换选中”，已有结果仍另存。
5. “打开输出目录”优先打开选中结果的目录，未选中结果时打开最近完成结果的目录。移除或清空只改变列表，不删除源文件和结果。

标题和输出设置会记住上次选择，模板在每次打开时恢复为中文通用。安装版设置位于当前用户LocalAppData/md2word/settings.json，便携版通过程序旁的portable.flag改为程序目录保存。不扫描其他旧便携文件夹。目录不可写时提示“本次选择仍可使用”，不阻止转换。关闭运行中的窗口会先取消任务、清理临时文件，再退出。“关于与帮助”提供离线说明、版本、主页及反馈链接；只在主动点击链接时打开网页。

键盘：Ctrl+O添加文件，Tab切换控件，Alt+A添加，Alt+R移除，Alt+S开始。文件行获得焦点后，↑/↓移动、Shift扩展选择、空格切换选中，Enter打开结果，F4展开或收起原因；Ctrl+A全选、Delete移除。文本框中的Ctrl+A和Delete保留编辑行为；转换时Esc取消。

当前已做事件级拖放、键盘和打开路径检查，以及本机125%显示缩放和100%~200%布局模拟。资源管理器手工拖放、系统对话框、真实关联程序打开及跨显示器DPI切换仍需人工试用，未视为已验证。

## 准备与构建

在项目根目录使用PowerShell7运行：

```powershell
pwsh -File .\scripts\bootstrap.ps1
pwsh -File .\scripts\bootstrap-pandoc.ps1
pwsh -File .\scripts\build.ps1
```

bootstrap从微软官方源下载SDK并比对SHA512，只解压到.tools/dotnet；不替换系统SDK。构建同时运行测试。若本机代理不可用且需要直连，可给两个脚本添加`-DirectNetwork`；构建脚本的代理调整只在本次运行中生效。

SDK10.0.402由global.json固定，NuGet依赖由packages.lock.json固定；.tools、编译结果和artifacts生成物不纳入源码版本控制。构建和测试需要允许MSBuild及测试宿主启动子进程。

新克隆仓库不带Pandoc程序。bootstrap-pandoc.ps1按release/portable.json中的官方ZIP和程序SHA256核对后准备本地依赖；遇到现有程序摘要不符时停止，不覆盖来源不明的文件。可加`-DirectNetwork`直连。该脚本只在开发时下载，用户实际转换无需联网。

构建执行转换与桌面两组测试，默认报告为artifacts/test-results/latest.trx及latest-desktop.trx。可用`-TestReport custom`另存报告。权限测试只临时限制本次创建的测试目录，并在结束前恢复权限、验证可重新写入。

## 制作安装及便携候选包

开发机使用PowerShell7.2或更高版本：

```powershell
pwsh -File .\scripts\bootstrap-inno.ps1
pwsh -File .\scripts\publish.ps1
```

脚本在artifacts/releases下创建独立候选目录，生成主要下载文件Setup.exe、备用ZIP、source-materials源码材料、SHA256SUMS.txt及体积报告SIZE.md。安装包为当前用户安装，默认不创建桌面快捷方式；使用固定AppId升级，运行中的桌面实例通过命名互斥体阻止替换，不强杀进程。卸载保留设置和用户文档，不改文件关联。备用ZIP完整解压后运行，保留portable.flag；查看DOCX需要相应软件。候选包自带简短说明和发布状态。

本轮GitHub附件不上传便携ZIP，ZIP仅本地保留用于检查与备用；普通用户入口只展示安装包。源码材料ZIP仍随发行材料提供，用于开发和许可核查，不是便携运行包。

版本统一来自release/version.props。Inno Setup7.1.0以官方PORTABLE模式展开到.tools/inno，不修改文件关联或创建工具快捷方式；下载SHA256及官方发布资产元数据来源见release/inno.json，同时核对官方签名。当前候选包不签名。仅制作便携包时可使用-SkipInstaller。

publish.ps1 -PublicRelease仅制作正式发行材料，不自动上传。它要求release/public-readiness.json所有检查有通过证据、工作树干净、版本不含候选后缀、HEAD标签与版本一致；当前未达门槛，应失败退出。完成检查后不能以预发布标签替代源码及分发材料要求。

可下载预发布另用`-PreviewRelease -PandocBundleDirectory .tools/pandoc-bundle`：必须是干净的候选版本，并逐项核对自行构建的Pandoc程序和完整源码材料；兼容性未验证项继续记录。手动执行“Build Pandoc with corresponding sources”取得成对的程序和源码材料，再用“Build offline installer preview”选择该成功运行的编号。后者测试新Pandoc、打包并检查，只上传未发布草稿，不上传便携ZIP或自动公开软件。

测试可设置MD2WORD_TEST_PANDOC指向待核对程序；不设置时仍使用开发目录中的官方程序。此变量仅用于测试，不改变CLI或转换核心接口。

scripts/clean-artifacts.ps1默认仅预览，保留最新两次完整候选目录。旧候选仅清理CLI及官方程序展开中间目录；重复应用展开副本须与完整文件清单一致，且保留的ZIP摘要有效才能列入。存在额外文件或用户文档时跳过。只有显式-Apply才删除；源码快照、包及验收记录保留。路径限制在artifacts/releases，遇到链接停止。scripts/measure-size.ps1生成下载、展开、组件及开发目录占用统计，不保证换安装格式就明显缩小。

release/portable.json固定win-x64、运行时10.0.13及Pandoc、模板校验值。便携还原使用packages.win-x64.lock.json，开发还原继续使用packages.lock.json。首次准备需要下载运行时；正式转换不下载依赖，网络图片保留占位提示。代理不可用时，发布脚本可加`-DirectNetwork`。

检查指定候选目录：

```powershell
pwsh -File .\scripts\verify-portable.ps1 -ReleaseDirectory '<候选目录的实际路径>'
```

检查从ZIP解压，在精简PATH和无效DOTNET_ROOT的子进程中启动与转换，再移动整个程序目录复测。报告写入候选目录verification.json。子进程使用不可用代理，但没有切断整机网络；这不能替代无开发环境、实际断网的目标电脑验证。

候选包提供当前工作树的源码快照及逐项摘要，BUILD.json记录基线提交和本地修改状态。Pandoc标签源码仅标记为已归档材料，不认定完整对应源码齐全。此步骤不创建GitHub仓库、不上传文件，也不执行正式Release。

## 准备第三轮试用

先对候选执行verify-portable.ps1并确认通过，再准备本地审查材料。将实际候选路径传入：

```powershell
.\scripts\build-trial-kit.ps1 -ReleaseDirectory '<候选目录的实际路径>'
```

输出位于artifacts/trials，包含候选安装器、3份合成样例、缺图与修复练习、待填反馈表、验证人员说明和文件摘要，不改动已有候选包。准备材料不代表用户已试用，也不自动对外发送。验证准备包时，将实际生成的“md2word试用准备”目录传给verify-trial-kit.ps1的-KitDirectory，并传入同一-ReleaseDirectory。

verify-trial-kit.ps1验证文件摘要、真实CLI转换、缺图修复、图片内容和另存保护；它不执行用户日常安装的卸载，不改变网络或执行策略。收集环境.ps1仅供验证人员可选使用，兼容Windows PowerShell5.1，不包含个人路径或正文，不自动填写人工验收结果。目标环境与试用要求见[目标电脑与用户试用](目标电脑与用户试用.md)。

## 转换文件

```powershell
pwsh -File .\scripts\convert.ps1 -InputFiles .\tests\fixtures\basic.md -Template cn-general -OutputDirectory .\artifacts\my-documents
```

多个文件可在PowerShell中调用：

```powershell
.\scripts\convert.ps1 -InputFiles @('.\tests\fixtures\basic.md', '.\tests\fixtures\tables.md') -Template cn-general -OutputDirectory .\artifacts\my-documents
```

- `cn-general`：明确选择CN-General，统一中文标题、编号和表格格式。
- `original`：不套用CN-General，保留原有列表类型、编号起点和强调，使用Pandoc基础Word样式。
- 默认提取文首第一个一级标题；关闭时添加`-KeepHeadingLevels`。没有文首一级标题时，用文件名作为文档标题。
- 不指定输出目录时保存到源文件目录。重名时使用“文件名（2）.docx”等新名称，不覆盖原文件。
- 输入按GFM解析，仅接受UTF-8。代码块内的Markdown标记保留原样；普通Markdown的强调仍遵循GFM分隔符规则。
- 图片位置相对Markdown解析，支持中文、空格及URL编码路径。本地PNG/JPEG先检查能否解码，缺图、损坏或格式与扩展名不符时失败。网络图片不下载，保留原说明和占位，结果显示“已完成，请检查”。
- 图片按比例缩小到页面或单元格内，不放大；纵向尺寸为标题、说明及行距留出空间。超长图片缩小后文字可能较小，建议在源文档中拆分图片。
- 用Ctrl+C取消命令行任务；仅终止本次转换进程，已完成文件保留，临时文件清理失败时给出具体提示。

查看命令行帮助：

```powershell
.\.tools\dotnet\dotnet.exe .\src\Md2Word.Cli\bin\Release\net10.0\Md2Word.Cli.dll --help
```

开发辅助脚本会显式传入现有Pandoc位置。直接运行CLI时，使用`--pandoc`指定3.10程序；未指定则查找应用目录中的pandoc/pandoc.exe。资源从应用目录读取，不依赖个人技能目录。

退出码：0为成功或带警告完成，1为至少一个文件转换失败，2为参数使用错误，130为取消。带警告结果的具体原因写入诊断输出。

## 工程与资源

| 位置 | 用途 |
|---|---|
| src/Md2Word.Core | 共用异步转换接口、Pandoc调用、资源检查及Open XML后处理。 |
| src/Md2Word.Cli | 真实转换入口。 |
| src/Md2Word.Desktop | 真实WinForms界面、文件队列、结果交互及应用目录设置保存。 |
| tests/Md2Word.Tests | 真实Pandoc转换及文件保护、取消等测试。 |
| tests/Md2Word.Desktop.Tests | WinForms消息循环内的真实转换、交互事件、权限和布局检查。 |
| tests/fixtures | 16份固定合成输入及自制PNG/JPEG图片。 |
| resources/convert.lua | 标题、顶层列表及引导词强调的语义处理。 |
| templates/cn-general | 项目内参考文件、预览、规则和来源记录。 |
| pandoc-3.10、third_party | 保留原始程序与源码归档，维护来源、校验和许可材料。 |
| release、scripts/publish.ps1 | 便携配置、使用说明、候选发布状态及自包含打包。 |
| scripts/verify-portable.ps1 | 从ZIP解压、隔离开发环境变量、实际转换和目录移动检查。 |
