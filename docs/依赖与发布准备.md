# 依赖与发布准备

## 已固定的开发依赖

- 项目SDK10.0.402，运行时10.0.13，来自微软官方2026年10月13日发布记录。SDK位于.tools/dotnet，global.json禁用版本滚动，不替换系统SDK。
- 下载地址：https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.402/dotnet-sdk-10.0.402-win-x64.zip
- 官方SHA512：`ae4fd528cb7e9f6af6aaf7de36715a69f761f183744f1bb3025d19f5a92447090ec561410e46266c1d10a63781ed6f3de771760bc76c876d87daabc367b898cd`。bootstrap.ps1下载后比对，再解压。
- 校验来源：https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json
- Pandoc保持3.10，原程序和源码归档不修改。开发入口显式传入本地路径；直接运行CLI时使用--pandoc配置，默认查找应用目录内pandoc/pandoc.exe。
- Open XML SDK使用3.5.1；依赖和测试工具版本见项目文件与packages.lock.json。构建默认执行锁定还原，版本变化须明确更新锁文件并重新验证。
- 图片解码使用System.Drawing.Common10.0.2，传递依赖Microsoft.Win32.SystemEvents10.0.2；nuspec均声明MIT，锁文件已更新。此能力仅面向Windows10及更高版本，不把Core与界面分离描述为跨平台支持。API依据：[微软Image.FromStream说明](https://learn.microsoft.com/en-us/dotnet/api/system.drawing.image.fromstream?view=windowsdesktop-10.0)，包来源：[官方NuGet包](https://www.nuget.org/packages/System.Drawing.Common/10.0.2)。

## 产品选择与环境

Windows10和Windows11的x64电脑均为交付验证目标；Word为主要排版验收软件；自有代码及自制CN-General模板采用MIT；离线Setup.exe为主要交付，便携ZIP为备用，均随附Pandoc和运行时。

当前仅在Windows10专业版22H2、Build19045上完成转换及桌面本机自动检查，实际桌面显示缩放为125%。开发入口仍使用项目SDK；另有包含.NET10.0.13和Pandoc的win-x64自包含候选包。微软当前支持表将Windows10限制为表列LTSC/Enterprise版本；本机专业版22H2运行通过不表示其属于官方支持范围。Windows11及干净电脑的实际结果分别记录。

官方依据：https://learn.microsoft.com/en-us/dotnet/core/install/windows#supported-versions

## 后续发布门槛

1. 完成转换能力、实际桌面交互和完整样本验收。
2. 发布win-x64自包含目录包，保持Pandoc为独立程序，程序和模板路径均不依赖开发机目录。
3. 整理.NET运行时、Open XML SDK等运行依赖的实际许可文本。
4. 核对Pandoc二进制来源、完整对应源码、依赖及构建材料；源码材料与便携包在同一Release提供。
5. 完成CN-General公开许可及元数据检查，不附带字体文件。
6. 在无SDK、无独立Pandoc安装的Windows10和Windows11电脑上检查解压、移动目录和离线转换。

已有本地自包含候选包、源码快照、Pandoc标签源码归档及校验材料；官方Windows ZIP摘要和原程序四个文件逐项一致。发布脚本收集实际运行时和Open XML SDK许可，保留NuGet来源、内容哈希、包归档摘要及仓库提交。

干净电脑、Windows11及WPS验证仍待完成。44项核心及23项桌面检查通过；软件发行范围见[发布状态](../release/RELEASE-STATUS.md)。Pandoc完整对应源码仍未齐全，具体缺项见[Pandoc源码材料](Pandoc源码材料核对.md)，源码归档及本机运行通过不等同于正式软件发行就绪。
