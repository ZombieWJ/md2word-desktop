# 展示材料说明

README展示真实运行的WinForms控件、实际生成的DOCX及Microsoft Word15.0/Build15.0.5589导出的页面。所有业务内容均为合成样例。

## 样例与页面

| 样例 | 页面 | 检查重点 |
|---|---|---|
| 协作文档库试运行周报 | 1页 | 分级标题、第一页进展表、下周安排。 |
| 表格 | 1页 | 表头、黑框、单元格边距与表后正文。 |
| 中英文与图片 | 1页 | 单位、0xFF、0b1010、链接、代码及完整项目介绍图。 |

Word以只读方式打开DOCX并导出PDF，再由Poppler转为PNG；实际页面已逐页查看，未见文字重叠、表格越界或图片裁切。DOCX作者及最后编辑者字段为空，没有嵌入字体文件。结果仅覆盖这些输入和所记录软件版本。

输入、结果、页面及原图摘要保存在[showcase.json](assets/showcase.json)，复现方法见[样例说明](../examples/showcase/README.md)。原图按字节嵌入DOCX，转换不改写内容或换算进制。

## 演示采集方式

demo.gif为5帧、24秒的步骤回放：打开工具、添加文件、查看结果、检查Word页面、保留图文。界面由真实MainForm执行3份输入转换后通过DrawToBitmap采集，Word画面来自实际PDF页面。帧停留时间经过调整，因此不是连续屏幕录像或性能计时；app.png为125%缩放下的控件画面。

scripts/capture-showcase.ps1执行实际转换并采集控件，scripts/build-showcase-assets.py使用已有帧和Word页面制作对照与GIF，scripts/verify-showcase.py检查本地链接、文件摘要、帧数、DOCX结构及嵌入图片。结构检查不能代替Word逐页检查、系统操作或干净目标环境验收。
