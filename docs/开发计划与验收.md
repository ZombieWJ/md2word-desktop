# 当前状态与后续计划

当前应用版本为0.1.0-rc.5。转换核心、CLI和WinForms桌面程序共用转换逻辑，安装候选包及备用便携ZIP可在本机构建；安装包公开下载仍取决于发行材料核对。

本轮GitHub附件只提供安装包及必要源码与核查材料，便携ZIP仅本地保留，不上传。

## 已实现

- UTF-8 GFM、标题层级、自动编号、基础表格、代码、链接和本地PNG/JPEG图片。
- 串行批量转换、单文件失败后继续、取消后继续、失败重试及显式重新转换。
- 重名另存、临时文件清理、源文件保护、缺图提示和远程图片占位。
- 默认中文通用模板、保留原有列表和加粗方案、结果打开与定位、版本帮助及脱敏诊断。
- 当前用户安装、设置保存、覆盖升级、卸载保留设置及用户文档。

## 正式发行前待完成

1. 取得并核对所分发Pandoc二进制的完整对应源码、精确依赖与构建材料，见[Pandoc材料](Pandoc源码材料核对.md)。
2. 在无开发环境的Windows10/11目标电脑上执行真实断网安装、转换、移动目录、升级、卸载及重装。
3. 完成原生文件与文件夹对话框、资源管理器拖放、关联程序打开、完整键盘操作、实际显示缩放及跨屏检查。
4. 3名非开发用户试用按维护者要求移至后续，不作为本轮强制前置条件，也不标为已通过。见[实机记录](实机验证记录.md)及[试用检查表](目标电脑与用户试用.md)。
5. 满足发布门槛后，从干净源码及实际版本标签生成正式材料；首个正式版本拟为v0.1.0。

首版不包含网页转换、实时分页预览、模板编辑器、账号、遥测、自动更新、公式及Mermaid渲染。WPS、Windows11及其他Word版本尚未通过排版验收。
